Lộ Trình Cây Kỹ Năng Đồ Thị (DAG)

Áp dụng Đồ thị có hướng không chu trình (Directed Acyclic Graph) để quản lý điều kiện tiên quyết của học phần

TIER 1 (NỀN TẢNG)
HTML5 Semantic

Cấu trúc trang web, thẻ ngữ nghĩa, bảng biểu và biểu mẫu chuẩn W3C.

TIER 2 (GIAO DIỆN)
CSS3 & JavaScript

Flexbox, Grid layout, Responsive design và tư duy lập trình JS ES6+ Client.

TIER 3 (TƯƠNG TÁC)
DOM & Form Events

Tương tác cây DOM, xử lý sự kiện và kiểm tra hợp lệ dữ liệu biểu mẫu Client-side.

TIER 4 (BACKEND)
HTTP & Python Flask

Kiến trúc Client-Server, Web APIs, Database ORM và triển khai dịch vụ Web Cloud.

Auto-Judge & Sandbox Cô Lập

Mỗi bài nộp được kiểm thử an toàn qua tiến trình con với Timeout & Memory Limit


def run_testcase_in_sandbox(language: str, source_code: str, stdin_data: str, 
                            expected_output: str, time_limit_ms=1000) -> SandboxResult:
    # 1. Tạo file mã nguồn tạm thời trong môi trường cô lập
    # 2. Thực thi thông qua Subprocess với timeout nghiêm ngặt
    try:
        proc = subprocess.run([python_bin, temp_file], input=stdin_data, 
                              capture_output=True, text=True, timeout=time_limit_ms / 1000)
        # 3. Chuẩn hóa đầu ra và đối chiếu với đáp án chuẩn
        if normalize_output(proc.stdout) == normalize_output(expected_output):
            return SandboxResult(verdict="AC", memory_kb=mem_used, time_ms=elapsed)
        return SandboxResult(verdict="WA", actual_output=proc.stdout)
    except subprocess.TimeoutExpired:
        return SandboxResult(verdict="TLE") # Xử lý quá thời gian quy định
AC: Accepted
WA: Wrong Answer
TLE: Time Limit Exceeded
AI Feedback: Gợi ý sư phạm tự động khi WA

Phân Quyền & Kịch Bản Demo

Hệ thống hỗ trợ 4 phân quyền hoàn chỉnh tương ứng với từng tác vụ

1. Khách Vãng Lai (Guest)

• Khám phá Cây kỹ năng và danh mục bài học demo.
• Thực hiện Test Đầu Vào (Placement Test) để phân tích năng lực và tự động xếp lộ trình phù hợp.

2. Học Viên (Learner)

• Đọc bài giảng lý thuyết theo từng chương NEU.
• Làm bài tập thực hành, nhận kết quả AC, tích lũy XP, kết nối Bạn học và mở khóa Node tiếp theo.

3. Giảng Viên / Mentor

• Cổng Mentor Portal: Xem báo cáo tiến độ học tập của từng sinh viên.
• Hỗ trợ giải đáp và định hướng học tập cá nhân hóa.

4. Quản Trị Viên (Admin)

• Quản lý ngân hàng câu hỏi test đầu vào và đề bài tập.
• Giám sát trung tâm an toàn nội dung chat và xử lý báo cáo.
